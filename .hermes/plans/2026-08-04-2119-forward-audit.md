### Phase A: WebSocket Module Fixes

#### A.1 `_recv_with_timeout` exception handling (MEDIUM)
**Target**: `src/nexusagent/server/websocket.py:34-40`

**Current code (lines 34-40)**:
```python
async def _recv_with_timeout(websocket: WebSocket, timeout: float = _WRAPPED_TIMEOUT):
    try:
        return await asyncio.wait_for(websocket.receive_text(), timeout=timeout)
    except asyncio.TimeoutError:
        return None
    except Exception:
        return "__DISCONNECT__"
```

**Finding**: ✅ **CONFIRMED** — The bare `except Exception:` at line 39 catches ALL exceptions including `WebSocketDisconnect` and treats them identically to other errors. The plan correctly identifies this loses error distinction.

**Proposed fix feasibility**: ✅ **FEASIBLE** — Can catch `WebSocketDisconnect` explicitly before the general `Exception` clause.

**Existing test**: `test_websocket_timeouts.py:46-52` already tests the `__DISCONNECT__` sentinel on generic exception, but does NOT test that `WebSocketDisconnect` is distinguished.

#### D.3 Local `import math` style (NIT)
**Target**: `src/nexusagent/memory/memory_files.py:213-222`

**Current code (lines 209-222)**:
```python
@staticmethod
def _compute_quality_score(content: str, confidence: float | None = None) -> float:
    """Compute initial quality score for a memory entry.

    Based on content length (longer = more detailed) and confidence.
    Score range: 0.0 - 1.0
    """
    import math

    length_score = min(math.log(max(len(content), 1)) / math.log(1000), 1.0)
    confidence_score = confidence if confidence is not None else 0.5
    score = 0.6 * length_score + 0.4 * confidence_score
    return round(score, 2)
```

**Finding**: ✅ **CONFIRMED** — Local `import math` at line 216 inside staticmethod.

**Proposed fix feasibility**: ✅ **FEASIBLE** — Move `import math` to module top (line 26-33 area).
